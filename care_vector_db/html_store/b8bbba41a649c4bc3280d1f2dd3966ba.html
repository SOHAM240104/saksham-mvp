In the Find My app, you can turn on separation alerts for an AirTag or other item so you don’t accidentally leave it behind. You receive an alert every time the separates from the item.

In order to receive separation alerts, make sure you allow notifications for the Find My app. See .

  1. Tap Items at the bottom of the screen, then tap the name of the item you want to set an alert for.

  2. If you want to add a Trusted Location, you can choose a suggested location, or tap New Location, select a location on the map, then tap Done.
